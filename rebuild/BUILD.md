# Rebuild workspace

The source used for this branch is under `rebuild/`.

`rebuild/MultiplayerCampaignSubModule.cs` is the complete copied campaign core.
`rebuild/MultiplayerCampaignEnhancements.cs` is the companion runtime layer for the character-slot, independent-player, time, movement, world-state and crash-safety work.
`rebuild/MultiplayerCampaign.xml` is the matching multiplayer UI.
